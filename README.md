# 🎰 TheGrandFiveBot

Многофункциональный игровой Telegram-бот на aiogram 3, написанный на Python.

## 🚀 Функционал

- 🎰 Казино и азартные игры: слоты, рулетка, кости, монетка
- 👤 Профиль игрока: статистика, баланс, темы оформления
- 💳 Донат-система: покупка VIP-статусов и игровой валюты
- 💾 База данных: сохранение прогресса и настроек пользователей

## 🛠 Технологии

- **Python 3.12**
- aiogram 3.x — асинхронный фреймворк для Telegram Bot API
- SQLite / AIOSQLite — база данных
